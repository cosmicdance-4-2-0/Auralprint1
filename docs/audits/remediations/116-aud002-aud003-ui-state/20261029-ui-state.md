## Changes

`scene-panel.js` uses the existing `bindConfigRange` / `readConfigRange` /
`syncConfigRange` contract for all three Scene palette sliders. CONFIG still owns
bounds/steps; imports retain precision, while readout/ARIA distinguish the canonical
value from the editing selection. Refresh never commits that selection.

`ui.js` propagates `replaceDrafts` only for Reset All Settings and successful winning
imports, including native compressed imports. `orb-editor.js`, `scene-panel.js` and
`analysis-panel.js` clear obsolete text/errors and synchronize canonical values even
when scalar values or settings references are unchanged. Orb picker range drafts
receive the same intent through `orb-band-picker.js`; ordinary synchronization keeps
their draft policy. Old Analysis/Orb status errors clear too. Exact-band equality
checks prevent late blur/change events from committing replacement values again.

Editor reconciliation keeps the focused card connected and orders its siblings from
right to left. Surviving controllers/listeners remain intact, with no focus restoration,
global clearing or controller reconstruction. Removed cards receive no focus action.
Ordinary edits retain runtime/history and camera semantics.
